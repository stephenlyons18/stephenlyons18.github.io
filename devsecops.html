GitHub Actions Workflows

Security-first CI/CD pipelines that protect this repository at every stage — from commit to deployment.

Security should never be an afterthought. These GitHub Actions workflows integrate security scanning, code quality enforcement, and site integrity checks directly into the development pipeline. Every push and pull request is automatically validated before code reaches production.

This is the same DevSecOps philosophy I apply at Yamaha Motor Corporation — embedding security gates into CI/CD workflows so vulnerabilities are caught early and consistently.

🔐

Secret Scanning with TruffleHog

.github/workflows/secret-scanning.yml

TruffleHog scans every commit and pull request for accidentally committed secrets — API keys, tokens, passwords, and other credentials that should never appear in version control.

If a secret is detected, the workflow fails immediately and annotates the PR with the findings, preventing sensitive data from reaching the main branch.

Features

  • Scans all commits in push events and PR diffs
  • Detects high-entropy strings, regex-matched patterns, and known secret formats
  • Fails the CI pipeline on any detected secret
  • Annotates pull requests with detailed findings
  • Triggers on push to main/master and all pull requests
# .github/workflows/secret-scanning.yml
name: Secret Scanning
on:
  push:
    branches: [main, master]
  pull_request:
jobs:
  trufflehog:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: trufflesecurity/trufflehog@main

Automated Code Formatting Check

.github/workflows/code-formatting.yml

Consistent code style improves readability, reduces merge conflicts, and makes code review more efficient. This workflow runs Prettier on every pull request to enforce formatting standards across HTML, CSS, and JavaScript files.

If formatting issues are detected, the workflow fails with a clear diff showing exactly what needs to be fixed. Developers can auto-fix locally with npx prettier --write .

Features

  • Checks HTML, CSS, and JavaScript files for formatting consistency
  • Fails on any formatting violations with actionable diff output
  • Easy local fix with a single Prettier command
  • Triggers on all pull requests
  • Lightweight — runs in seconds
# .github/workflows/code-formatting.yml
name: Code Formatting
on:
  pull_request:
jobs:
  prettier:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npx prettier --check "**/*.{html,css,js}"

Broken Link Checker

.github/workflows/link-checker.yml

Broken links erode user trust and harm SEO. This workflow scans all HTML files for broken internal and external links on a weekly schedule and on every push to main.

When broken links are found, the workflow creates a GitHub Issue with a detailed report, making it easy to track and fix link rot over time.

Features

  • Scans all HTML files for internal and external broken links
  • Runs weekly (Mondays) and on push to main
  • Creates GitHub Issues for any broken links found
  • Configurable exclusion patterns for known-flaky URLs
  • Supports both relative and absolute link validation
# .github/workflows/link-checker.yml
name: Link Checker
on:
  schedule:
    - cron: '0 9 * * 1' # Every Monday at 9 AM
  push:
    branches: [main]
jobs:
  linkchecker:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: lycheeverse/lychee-action@v2

Enabling GitHub Advanced Security

To get the most out of these workflows, consider enabling GitHub Advanced Security features on your repository:

  • Navigate to Settings → Code security and analysis in your repository
  • Enable Dependency graph for vulnerability scanning of dependencies
  • Enable Dependabot alerts to get notified about vulnerable dependencies
  • Enable Dependabot security updates for automated fix PRs
  • Enable Code scanning (with CodeQL) for static analysis of your codebase
  • Enable Secret scanning (native) as an additional layer alongside TruffleHog
  • Consider enabling Push protection to block secrets at push time before they enter history
