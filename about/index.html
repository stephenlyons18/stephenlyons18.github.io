Summary

Professional Background

I'm a Cybersecurity Engineer at Yamaha Motor Corporation with a strong foundation in both offensive and defensive security practices. My work spans DevSecOps, cloud infrastructure security, SIEM engineering, endpoint protection, and incident response.

I build and maintain CI/CD pipelines with security checks baked into every workflow, manage enterprise security tools including CrowdStrike, Netskope, and Zscaler, and develop infrastructure as code using Terraform and Ansible. My approach emphasizes automation, continuous monitoring, and proactive threat detection.

Before focusing on security, I honed my skills as a full-stack web developer, which gives me a deep understanding of the systems I protect. I hold a B.S. in Computer Science from Cal State Long Beach with a minor in Cyber Security Applications.
